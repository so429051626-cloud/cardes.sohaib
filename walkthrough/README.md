# Apartment walkthrough (interactive 3D)

A walkable, phone-first 3D model of the apartment described in the brief. Everything is generated by code at load time: three.js geometry, GPU-procedural textures, canvas-drawn artworks and a seeded PRNG (mulberry32). Nothing is downloaded at run time.

Signature: **Py | Sohaib Qudeih**. It appears in a decorative script (Great Vibes, embedded) on the loading screen, as a small HUD mark, in the menu footer, and as backlit brass lettering on the reception wall.

## Build

```bash
npm install          # three@0.187.0, esbuild
node build.mjs       # -> dist/index.html (standalone) and dist/artifact.html (Claude artifact body)
```

`dist/index.html` is one self-contained file (about 1.2 MB): JS, CSS and fonts are inlined. It works offline and from `file://`.

## Test (headless Chromium, software WebGL)

```bash
node test/quick.mjs /tmp/shot 0 12.5 '--q=quality=medium&noadapt&manual&nohud'   # quick look at tour times
node test/qa.mjs --tour --touch --keys --shots                                    # full QA, writes screenshots/ and test/qa-report.json
python3 test/stats.py screenshots/portrait_*.jpg                                   # luma / saturation vs section 4.2
```

URL parameters, all optional:

| Parameter | Effect |
|---|---|
| `quality=high\|medium\|low` | force a preset (default: High on desktop, Medium on phones) |
| `noadapt` | disable adaptive quality |
| `manual` | no animation loop; drive frames with `window.__tour.frame()` |
| `nohud` | hide the UI (clean screenshots) |
| `exp`, `tm`, `lift`, `sat` | grade tuning (exposure, `neutral`/`aces`, black lift, saturation) |

Test hook: `window.__tour.goto(t)` puts the camera at auto-tour time `t` and returns `renderer.info` numbers.

## Controls

* Phone: joystick bottom-right walks, drag anywhere else to look, tap the floor to walk there, pinch to change the field of view.
* Desktop: W A S D or arrow keys to walk, Shift to walk faster, drag the mouse to look, wheel to zoom.
* Menu (top right): room list (tap to glide there), auto-tour, quality, fullscreen, mini plan with a "you are here" dot (tap the plan to walk there).

## Source layout

```
src/main.js            boot sequence, frame loop, portal culling, test hook
src/render.js          renderer, post chain (GTAO, bloom, grade, SMAA), presets
src/lighting.js        light pool (6 rect, 6 point, 1 shadowed sun, 1 hemi) + env probes
src/world.js           zones, static batching per material, colliders, portals
src/player.js          camera with lens shift, collision, nav grid + A*, input
src/tour.js            auto-tour keys from section 11 and checkpoints
src/arch/shell.js      walls/openings, floors, tray and cove ceilings, windows, curtains, doors
src/core/              PRNG, GPU texture generator + recipes, canvas art, materials, geometry kit
src/kit/               furniture builders (seating, tables, beds, storage, kitchen, bath, lights, decor, media, doors)
src/rooms/             per-room placement data (plan.js holds the floor plan)
src/ui/                Arabic RTL interface and page template
test/                  Playwright harness, QA script, stats
```
